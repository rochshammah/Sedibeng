# PHASE 1: BUILD SEDIBENG FROM SCRATCH — COMPLETE FOUNDATION AND PREMIUM UI

You are building a completely NEW application. This is a fresh Replit project. There is NO existing codebase, no existing database, no existing design, and no existing functionality to preserve. Do not waste time searching for or expecting existing project files. Create everything from scratch.

## 1. Product identity

Application name: **Sedibeng**

Official slogan: **“Sedibeng go iwa ka tsela”**

Sedibeng is a digital platform that connects verified teachers with donors who want to provide physical school essentials to underprivileged learners in Gaborone, Botswana.

Teachers submit assistance requests on behalf of learners. Donors can browse approved requests, list items they already have available to donate, or offer to provide specific items. Sedibeng helps match available donations with genuine needs.

The platform must protect learners' identities and dignity. Learners must never need to create accounts.

The initial pilot will operate in Gaborone, Botswana, but the architecture must allow expansion across Botswana in the future.

## 2. Technology stack

Build the application using:

- Frontend: React, TypeScript and Vite.
- Styling: Tailwind CSS.
- Components: shadcn/ui where appropriate, customised to match the Sedibeng design.
- Backend: Node.js, Express and TypeScript.
- Database: PostgreSQL hosted on Neon.
- ORM: Drizzle ORM.
- Frontend deployment: Vercel.
- Backend deployment: Render.
- PWA: installable Progressive Web App.
- Icons: Lucide icons, used sparingly.
- Forms: React Hook Form and Zod where appropriate.

Use a clean modular architecture, preferably:

- `/client` — frontend.
- `/server` — backend.
- `/shared` — shared types, schemas and validation.

Keep the application organised, scalable and maintainable. Do not place the entire application in one giant file.

## 3. Visual identity and design direction

This is extremely important. I want Sedibeng to look like a premium, professionally designed 2026 application, not an ordinary outdated administration dashboard.

The visual direction should combine:

- The refined visual quality of modern iOS interfaces.
- Premium fintech application design.
- Contemporary editorial website design.
- Human-centred education and social-impact photography.
- Subtle Liquid Glass-inspired surfaces and transitions.

Do not copy Apple's logo, branding or proprietary interface designs. Create an original Sedibeng identity.

### Colour palette

Use a sophisticated palette consisting of:

- Deep midnight navy as the primary dark colour.
- Teal/turquoise as the main accent.
- Warm off-white backgrounds.
- White surfaces.
- Soft neutral greys.
- Restrained gradients and subtle highlights.

The result should feel trustworthy, welcoming, elegant and modern.

### Typography

Use a refined heading font and a highly readable sans-serif body font. Establish a consistent hierarchy between page headings, section headings, descriptions, labels and supporting information.

Avoid oversized typography everywhere. Make the interface editorial and balanced.

### Photography — very important

I want the application to use high-quality, relevant photographs prominently.

Use photographs representing:

- School shoes.
- School uniforms.
- School backpacks.
- Stationery and textbooks.
- Classrooms.
- Teachers helping learners.
- School supplies being prepared or donated.
- Education activities.

Use reliable image assets or properly generated assets. Do not use random images that have nothing to do with the content. Do not leave broken image URLs or empty image placeholders.

Use suitable aspect ratios, attractive image cropping, responsive image sizing and graceful fallbacks.

**Do not replace photographs with emojis or generic icons.** Icons should only support navigation, actions, statuses and small interface details.

### Interface styling

Use:

- Layered surfaces.
- Carefully controlled transparency and blur.
- Subtle shadows and depth.
- Refined rounded corners.
- Elegant cards.
- Smooth transitions.
- Premium hover and pressed states.
- Beautiful form controls.
- Well-designed dialogs and responsive sheets.
- Consistent spacing.

Do not make every component glass-like. Glass effects should be restrained and purposeful.

Avoid excessive icons, excessive gradients, unnecessary borders, cluttered layouts and generic dashboard templates.

## 8. Important product rules

These rules must guide the architecture and interface from the beginning:

- Donors provide physical school goods, not money.
- Sedibeng does not transfer money to teachers.
- No learner accounts.
- No direct donor-to-learner communication.
- Learners remain anonymous.
- Teachers must eventually be verified before publishing requests.
- Requests must eventually be moderated before public listing.
- Donors can offer existing inventory or provide requested items.
- Teachers must approve proposed matches before allocation.
- No public child photographs.
- No fabricated verification badges or fake trust indicators.
